# MS in Applied Artificial Intelligence (MSAAI) Portfolio
### University of San Diego Graduate Coursework & Code Archive

This repository serves as a centralized archive of academic coursework, machine learning implementations, deep learning models, and research completed during my Master of Science in Applied Artificial Intelligence at the University of San Diego.

Each course directory is structured with standardized subdirectories to maintain separation of concerns: `/notes`, `/labs`, `/homework`, and `/final-project`.

## Notebook Execution

Most programming files within this repository are structured as Jupyter notebooks (`.ipynb`). To review the interactive code and outputs:
1. Navigate to the targeted assignment subfolder.
2. Select the notebook file.
3. Utilize the execution link at the top of the file to initialize the notebook instance within a cloud runtime environment.
